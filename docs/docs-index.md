# FlowForm documentation

FlowForm documentation separates maintained understanding from work that may
change it.

- [[project-knowledge-index|Project Knowledge]] explains current product,
  software, data, security, infrastructure, operations, and engineering
  boundaries.
- [[development-workspace-index|Development workspace]] holds decisions, plans,
  investigations, migrations, debt, and historical work.

Folder heads are useful overviews, not tables of contents. Child pages exist
only for independently useful detail. Cross-links connect neighbouring subjects
without repeating their content.

Current code, tests, configuration, automation, and infrastructure definitions
remain authoritative. Project Knowledge records the durable model and its
evidence boundary; exact procedures belong with the implementation that
executes them. Historical documentation is context, not proof of present
behaviour.
