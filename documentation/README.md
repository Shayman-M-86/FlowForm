# FlowForm engineering documentation

FlowForm is an adaptive survey platform for building, publishing, distributing and reviewing surveys. This knowledge base describes its system architecture, component ownership, data boundaries, delivery environments and operating procedures.

Documentation is organized by **subject**, not repository. Each page identifies the current implementation, an accepted target design, or a proposal. The source repositories remain authoritative for executable behaviour; where a design differs from running code, the difference is documented explicitly.

Start with [System overview](architecture/system-overview.md), [Backend architecture](backend/architecture.md), [Data boundaries](data-security/data-boundaries.md) or [Environments](infrastructure/environments.md).

## Documentation states

- **Current** — verified against the implementation or deployment.
- **Target** — accepted design, not yet fully deployed.
- **Proposal** — under evaluation.
- **Historical** — retained for decision context.

Do not describe a planned migration as an existing capability. Link to the relevant source or decision when declaring a significant technical detail.
