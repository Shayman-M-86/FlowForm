# Environments

**Status: Current/target deployment mixture; confirm live topology before operational use.**

FlowForm has separate development and hosted execution concerns. The existing repository includes AWS-related infrastructure and deployment tooling. A hybrid architecture using self-hosted Proxmox services with cloud ingress and supporting services is being evaluated.

This page is the home for an environment inventory. For each environment record its purpose, public entry point, deployment repository, compute location, database location, secret provider and configuration source. Do not assume that the proposed Proxmox topology is already serving production traffic.

Related: [Network and services](network-and-services.md), [Deployment configuration](configuration.md).
