# Operational runbooks

**Status: Runbook index.**

A runbook defines a triggering condition, required access, safe prechecks, procedure, verification, rollback and escalation. Procedures should cover application deployment, proxy recovery, database connectivity, migrations, worker failures, monitoring, and secret rotation.

Do not publish untested recovery commands as authoritative. See [Incident response](incident-response.md) and [Backup and restoration](backup-and-restoration.md).
