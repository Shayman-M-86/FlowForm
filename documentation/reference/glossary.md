# Glossary

**Project** — workspace grouping surveys and related participants.

**Survey** — configurable questionnaire definition.

**Published version** — fixed survey content against which answers are collected.

**Participant** — person or admission context taking a survey.

**Response** — answer data associated with an execution of a published survey.

**Feature** — backend functional area owning API-oriented operations.

**Capability** — reusable application functionality independent of a single entry point.

**Runbook** — operational procedure with preconditions and validation.

**Decision record** — dated explanation of an architecture direction.
